## 5) Environment Variables (Baseline)
Ask Codex to create `.env.example` files, then fill values.

Minimum variables you will likely need:
- `NODE_ENV=production`
- `PORT=3000`
- `DATABASE_URL=<postgres-url>`
- `REDIS_URL=<redis-url>`
- `JWT_SECRET=<long-random-string>`
- `OPENAI_API_KEY=<key-if-used>`
- `ANTHROPIC_API_KEY=<key-if-used>`

Connector variables (needed for CDX-03/CDX-04):
- `SLACK_CLIENT_ID`
- `SLACK_CLIENT_SECRET`
- `SLACK_REDIRECT_URI`
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REDIRECT_URI`

## 6) Slack OAuth (Free Test Setup)
1. Go to Slack API site and create a new app from scratch.
2. Select your Slack workspace.
3. Add OAuth scopes for read-only access only.
4. Add Redirect URL (from your API callback route).
5. Install app to workspace.
6. Copy Client ID and Client Secret into your env vars.

Guidelines:
- Keep scopes minimal and read-only.
- Do not request write scopes for Day-1.

## 7) Gmail OAuth (Free Test Setup)
1. Open Google Cloud Console.
2. Create a project (example: `nexusos-day1`).
3. Enable Gmail API.
4. Configure OAuth consent screen in Testing mode.
5. Add your test user email.
6. Create OAuth Client ID (Web application).
7. Add redirect URI matching your API callback route.
8. Copy Client ID and Client Secret into env vars.

Guidelines:
- Testing mode is enough for Day-1.
- Use only read scopes needed for message metadata/content reading.

   - ingest -> normalize -> workflow -> score -> war room

## 9) Cloud Preview Deployment (Public)

### 9.1 Deploy Web on Vercel
1. In Vercel, click `Add New -> Project`.
2. Import your GitHub repo.
3. Set root directory to web app path (as generated by Codex).
4. Add required web env vars.
5. Deploy.
6. Copy public preview URL.

### 9.2 Deploy API + Workers + DB + Redis on Railway
1. In Railway, create a new project from GitHub repo.
2. Add PostgreSQL service.
3. Add Redis service.
4. Add API service from repo path.
5. Add Worker service from repo path.
6. Set env vars for API and worker:
   - `DATABASE_URL` from Railway Postgres
   - `REDIS_URL` from Railway Redis
   - auth/model keys
   - OAuth credentials
7. Run migrations.
8. Confirm API health endpoint works.

### 9.3 Connect Web to API
1. In Vercel env vars, set API base URL to Railway API URL.
2. Redeploy web.
3. Open web URL and verify data loads.
